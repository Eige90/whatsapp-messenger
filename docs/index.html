Nachrichten planen. Lokal ausführen.

Ein persönliches Automatisierungswerkzeug für WhatsApp Web: Nachrichten vorbereiten, Zeitpläne festlegen und wiederkehrende Grüße mit optionaler Gemini-Unterstützung erstellen.

Lokal starten ↗Quellcode auf GitHub ↗

Diese Website ist die Projektseite. Das Dashboard und der Nachrichtenversand laufen lokal; der Rechner muss für geplante Sendungen eingeschaltet sein.

01 / So funktioniert es

Vom Entwurf zur geplanten Nachricht.

Kontakte & Texte

Kontakte lokal anlegen und Nachrichten mit Platzhaltern wie {{name}} personalisieren.

Planung

Versandzeiten und Wiederholungen über das lokale Dashboard festlegen.

Versand

Ein persistentes Chromium-Profil steuert WhatsApp Web und bei Bedarf Gemini Web.

Verlauf

Zeitpläne, Kontakte und Sendehistorie werden lokal in SQLite gespeichert.

02 / Zeitpläne

Einmalig oder wiederkehrend.

Unterstützt werden einmalige, tägliche, wöchentliche und jährliche Termine sowie ausgewählte Wochentage. Nach einem Neustart können verpasste Nachrichten geprüft werden. Fehlgeschlagene Sendungen werden erneut versucht.

Gemini kann optional personalisierte Texte erzeugen. Feste Nachrichten funktionieren ohne Gemini.

03 / Lokal starten

Installieren. Verknüpfen. Planen.

1. Voraussetzungen

Git, Node.js mit npm, Chromium/Chrome/Edge und WhatsApp auf dem Smartphone.

2. Projekt installieren

git clone https://github.com/Eige90/whatsapp-messenger.git
cd whatsapp-messenger
npm install
npm start

3. WhatsApp verknüpfen

Das lokale Dashboard öffnet sich unter http://localhost:3001. Beim ersten Start WhatsApp Web per QR-Code verknüpfen.

Die vollständige Einrichtung erklärt die optionale Gemini-Anmeldung und die lokale Konfiguration.
